# To-Do List — Project Statement

## Problem Statement

Managing daily tasks manually can be difficult and may lead to forgotten or incomplete tasks. This project provides a simple command-line To-Do List application that allows users to create, manage, search, and track their tasks efficiently.

## Scope of the Project

The project is a Python-based command-line application for personal task management. It stores tasks during program execution and provides options to add, view, update, delete, complete, search, filter, and analyze tasks.

## Target Users

- Students
- Individuals managing daily tasks
- Beginners learning Python programming
- Users who need a simple task-management system

## High-Level Features

- **Add Task** — Create new tasks.
- **View Tasks** — Display all available tasks and their status.
- **Update Task** — Modify an existing task.
- **Delete Task** — Remove a task from the list.
- **Mark as Completed** — Change a task's status to completed.
- **Search Task** — Find tasks by name or keyword.
- **Filter Tasks** — View pending, completed, or all tasks.
- **Task Statistics** — Display total, completed, pending tasks, and completion percentage.
- **Exit** — Safely close the application.
